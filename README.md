# TOWERD

A dependency-free browser tower defense game built with HTML5 Canvas, CSS, and JavaScript.

## Features

- 30 escalating waves
- Three tower classes: Dart, Cannon, and Frost
- Tower upgrades and selling
- Four enemy archetypes with different speed, health, and rewards
- Boss-style difficulty spikes through late-game tanks
- Splash damage, slowing, particles, screen shake, floating rewards
- Three game speeds
- Keyboard shortcuts
- Responsive UI
- No libraries, build tools, or downloads required

## Controls

- **1 / 2 / 3** — select tower
- **Space** — start the game or next wave
- **Mouse** — place/select towers
- **Escape** — deselect
- **R** — restart after defeat

The game is designed to run directly from GitHub Pages.
